# Maquettes des interfaces — Frostia Games

## 1. Objectif des maquettes

Les maquettes ont été réalisées avant l’intégration afin de définir :

- l’organisation générale des pages ;
- la hiérarchie des informations ;
- la navigation ;
- l’identité visuelle ;
- l’adaptation desktop et mobile ;
- les principaux composants réutilisables.

Elles ont servi de référence pendant le développement de l’interface.

---

## 2. Outil utilisé

Les maquettes ont été réalisées avec **Figma**.

Figma a permis de :

- organiser les blocs de contenu ;
- tester plusieurs dispositions ;
- préparer les versions desktop et mobile ;
- vérifier les proportions ;
- conserver une cohérence visuelle entre les pages.

---

## 3. Identité visuelle

L’identité de Frostia Games repose principalement sur :

- des tons bleus ;
- un fond clair ;
- des cartes visuelles ;
- des bordures discrètes ;
- une navigation facilement identifiable ;
- une présentation moderne et sobre.

L’objectif était d’obtenir un rendu professionnel sans utiliser un thème préfabriqué lourd.

---

## 4. Maquette desktop

La version desktop prévoit :

- une barre latérale de navigation ;
- une zone principale de contenu ;
- une hiérarchie claire entre les titres, les cartes et les informations ;
- une largeur adaptée aux écrans d’ordinateur ;
- un accès direct aux pages principales.

## 5. Maquette mobile

La version mobile prévoit :

- une navigation compacte ;
- un bouton de menu ;
- des cartes affichées verticalement ;
- des marges réduites ;
- des textes adaptés à la largeur disponible ;
- une consultation sans défilement horizontal.

## 6. Adaptation responsive

| Élément | Desktop | Mobile |
|---|---|---|
| Navigation | Barre latérale | Menu compact |
| Cartes | Plusieurs colonnes | Une colonne |
| Marges | Larges | Réduites |
| Titres | Taille importante | Taille adaptée |
| Contenu | Répartition horizontale | Empilement vertical |

---

## 7. Pages maquettées

### Page d’accueil

La page d’accueil présente :

- l’identité Frostia Games ;
- une courte introduction ;
- les principales catégories ;
- l’état actuel du projet ;
- des accès vers les autres pages.

### Page « Mes créations »

Cette page est destinée à présenter :

- les projets en préparation ;
- les concepts ;
- les travaux visuels ;
- leur état d’avancement.

### Page « Projets jouables »

Cette page est destinée à présenter :

- les projets accessibles ;
- les démonstrations ;
- les informations techniques ;
- les futurs liens de téléchargement ou d’accès.

---

## 8. Évolutions entre la maquette et le résultat final

Certaines adaptations peuvent avoir été réalisées pendant l’intégration pour :

- améliorer la lisibilité ;
- simplifier la navigation ;
- corriger une contrainte responsive ;
- adapter les composants aux données réelles ;
- réduire la complexité de la version 1.

Ces différences doivent être documentées à l’aide de captures comparatives.

## 10. Conclusion

Les maquettes ont permis de structurer le projet avant le développement et de limiter les modifications importantes pendant l’intégration.

Elles constituent une preuve de la réflexion menée sur l’ergonomie, la navigation et l’adaptation responsive de Frostia Games.
